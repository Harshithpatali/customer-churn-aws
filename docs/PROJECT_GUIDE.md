# Customer Churn Intelligence — Production Guide

## Architecture

The platform is organized into five layers:

1. Data engineering: schema validation, cleaning and deterministic feature engineering.
2. Statistical analysis: association tests and logistic-regression inference.
3. Machine learning: baseline comparison, 5-fold CV, hyperparameter search and threshold optimization.
4. Online serving: FastAPI prediction, readiness, batch scoring and SHAP explanation endpoints.
5. Decision UI: Streamlit analytics and customer-level decision support.

## Reproducible commands

python -m services.data_pipeline.run
python scripts/statistical_analysis.py
python scripts/train.py
python scripts/explainability.py
pytest -q

Or run the data, statistical and ML sequence with:

python scripts/run_pipeline.py

## Statistical methodology

Categorical variables use chi-square association tests and an effect-size proxy. Numeric variables use two-sided Mann-Whitney U tests. A compact logistic model produces odds ratios, confidence intervals, AIC, BIC and pseudo-R2.

These analyses describe association and inference context; they are not causal claims.

## ML methodology

The training layer compares Logistic Regression and XGBoost, then performs a stratified 5-fold randomized XGBoost search using average precision. The classification threshold is selected separately from probability estimation using a documented business objective.

## Explainability

Local SHAP explanations are exposed through the API. Global mean absolute SHAP importance is generated by scripts/explainability.py.
